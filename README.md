# AgriNexus

Autonomous Multi-Agent Agronomy & Zero-Trust Supply Chain Engine.

## Overview
AgriNexus is an enterprise-grade platform built to eliminate counterfeit farming inputs and diagnose crop diseases safely. 

## Features
- **Farmer UI**: Zero-friction, audio-first frontend for diagnosing diseases and validating seed packages.
- **Swarm Telemetry Control Room**: Real-time LangGraph state execution tracking and execution logs.
- **Vision Pathology**: Analyzes images for counterfeit packages or disease signatures using Gemini.
- **RAG Agronomy**: Grounded ICAR guidelines via embedded ChromaDB.
- **Deterministic Safety**: C++ core for pesticide toxicity validation and dosage generation.
- **Crop Passport**: Web3 Base Sepolia integration for immutable treatment ledgers.
- **Vernacular Audio**: Localized language translation and TTS synthesis.
